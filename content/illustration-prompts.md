# Illustration prompts — 25-cell art grid

Reve prompts for the 5×5 grid described in `PARTNER-BRIEF.md`. Paste each one
into Reve as-is; each is self-contained so they can be generated in any order
or re-rolled individually without losing consistency.

Save the result to the matching filename in `public/brand/`, replacing the
placeholder — do not rename.

## Shared style (baked into every prompt below)

Painterly ink-and-gouache illustration of a single scene inside an endless,
windowless lost-property archive: corridors, shelving, hooks, crates, hatboxes,
coats. Objects show real wear — dents, stains, frayed edges, scuffed labels.
No people, no faces, no hands, no text, no logos. Composition is close and
slightly off-center, as if someone is standing in the room rather than posing
it. Warm sourceless lamplight with soft falloff into shadow, fine crosshatching
in the dark areas, otherwise flat painterly washes of colour. No background
beyond the room itself — no windows, no sky.

Colour key: **amber** = warm honey and ochre · **crimson** = deep red and rust
· **verdigris** = oxidized copper-green and teal · **indigo** = ink-blue and
violet · **bone** = pale grey, cream, and off-white.

Mood key: **dormant** = still, settled, undisturbed dust · **restless** =
objects mid-motion or askew, implied movement · **tender** = small, cared-for,
gently framed · **ominous** = deep shadow, looming stacks, no visible cause ·
**absurd** = a wry, illogical-but-mundane excess.
